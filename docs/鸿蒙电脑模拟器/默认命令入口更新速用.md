# 默认命令入口修复版更新速用

适用：当前已经安装 `com.codex.emulatorhnp` 的鸿蒙 7 模拟器，应用 UID `20020059`。不需要管理员启动。请覆盖安装，不要先卸载。

原生版本：`0.160.0-dev.harmony.g8080943a2000`。源码：`8080943a200030b6fbcd5f00c3130bf58888da1a`。

当前状态：原生 CLI 和 HAP 已构建；新包的模拟器验收尚未完成。此包绑定模拟器应用 UID 20020059，不能作为实体 PC HiShell 的通用安装包。

## 在 Mac 更新

```bash
# 进入本次完整交付目录；解压到其他位置时，替换此路径。
cd "/Volumes/MacSSD/Repositories/codex/releases/2026-10-04-122811-鸿蒙Codex-默认Shell修复"
# 先核对安装包摘要，成功后覆盖安装，保留应用配置和工作区。
shasum -a 256 -c codex-harmony-terminal-debug.hap.sha256 && \
"/Volumes/MacSSD/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/toolchains/hdc" -t 127.0.0.1:5555 install codex-harmony-terminal-debug.hap
# 打开鸿蒙里的原生终端应用。
python3 ./manage-harmony-app.py open
```

## 在应用里使用

1. 点“启动 Codex”；标题中的版本应为上面的新版本。模型保持 `gpt-5.6-terra`。
2. 新会话初始仍为只读。当前模拟器的受限后端不可用；需要工具操作时，在 `/permissions` 中自行选择 Full Access。它仍受鸿蒙应用权限约束，并非系统管理员权限。
3. 让模型执行 `pwd`、`rg --files -g '*.html'`，不必再要求它指定 `/bin/bash` 或 `login=false`。`rg` 没有匹配文件时退出 1 是正常结果。

工作区是 `/data/storage/el2/base/files/workspace`。已有配置继续使用，不需要重新填写接口地址和 Key。输入斜杠命令前切换英文输入法；当前输入法可用 `Ctrl+空格` 切换。

## 取日志

```bash
# 在 Mac 导出脱敏日志；仅替换输出目录，保留原私有配置用于遮蔽 Key 和域名。
python3 ./manage-harmony-app.py collect-logs \
  --config "/Volumes/MacSSD/Repositories/codex/docs/鸿蒙电脑模拟器/config.toml" \
  --output "./终端日志-$(date +%Y%m%d-%H%M%S)"
```

日志包含任务内容，分享前检查。完整包不含用户接口配置。

本次只修复旧 Shell 快照中的多余 `exec sh`。包内原生 ELF 已作 SDK 自签名；HAP 外壳仍是当前模拟器接受的未签名调试包，不是商业 PC 的通用正式安装包。受限沙箱缺少的内核能力和 V8 Code Mode 没有因此得到补齐。
