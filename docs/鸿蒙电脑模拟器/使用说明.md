# 鸿蒙电脑模拟器一键启动

适用：当前 Apple 芯片 Mac、DevEco Studio 26.0.0、已经创建的 `MateBook Pro` 鸿蒙 7 模拟器。

命名约定：代码文件使用英文文件名；说明文档使用中文文件名和中文内容。

开发运行约定：需要编译时，先正常关闭模拟器并确认已退出；代码编译完成后再按下方入口打开调试。调试结束后若不需再次编译，保持模拟器运行，留给用户继续使用。仅编辑或查看资料不关闭，也不重置实例或删除数据。安装和包内生成脚本同样必须使用英文文件名。

## 启动

在 Finder 中双击本目录的 [start-harmony-pc-emulator.command](start-harmony-pc-emulator.command)。也可以复制执行：

```bash
# 启动已有的鸿蒙 7 PC 模拟器；已经运行时直接复用。
bash "/Volumes/MacSSD/Repositories/codex/docs/鸿蒙电脑模拟器/start-harmony-pc-emulator.sh"
```

脚本保留现有实例、应用和数据，使用实例已配置的启动方式；不会新建实例、下载镜像、升级系统或重置数据。首次出现华为许可协议时，由你阅读并在官方界面确认。

## 检查连接

```bash
# 只查看实例是否运行，以及 hdc 当前连接列表。
bash "/Volumes/MacSSD/Repositories/codex/docs/鸿蒙电脑模拟器/start-harmony-pc-emulator.sh" --status
```

出现 `Connected` 表示 hdc 已连接到对应行的设备；多设备时需要核对目标，脚本不替你选择设备。首次启动可能要等待开机，再运行上面的检查命令。

## 在 Mac 终端执行 hdc

这台 Mac 已经有 DevEco 自带的 `hdc`，实测版本为 `3.2.0f`，无需另外安装。在 **Mac 的终端 App** 中复制执行：

```bash
# 让当前 Mac 终端可以直接找到 DevEco 自带的 hdc。
export PATH="/Volumes/MacSSD/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/toolchains:$PATH"
# 查看 hdc 工具版本。
hdc -v
# 列出设备及连接状态。
hdc list targets -v
```

`export` 只对当前终端及其子进程生效，新开终端后可重新执行。启动脚本使用完整工具路径，不依赖这项 PATH 配置。

本次实际连接标识是 `127.0.0.1:5555`，状态为 `Connected`。以后若设备列表显示其他标识，请替换下列命令中的地址；同时连接多台设备时，使用 `-t` 明确指定目标。

```bash
# 在 Mac 终端输入，进入这台模拟器内部的交互式 Shell。
hdc -t 127.0.0.1:5555 shell
```

进入后可以执行：

```sh
# 查看模拟器内的当前目录。
pwd
# 退出设备 Shell，回到 Mac 终端。
exit
```

也可以直接在 Mac 终端执行一条设备命令，执行完自动返回：

```bash
# 只读查询模拟器系统版本，本次实测返回 OpenHarmony-7.0.0.105。
hdc -t 127.0.0.1:5555 shell 'param get const.ohos.fullname'
```

模拟器桌面没有终端 App 时，上述 HDC Shell 仍可用于基础调试。当前原生 Codex 已改用普通应用加官方 private HNP 安装，并使用真实配置收到 `gpt-5.6-terra` 回复。实际运行入口见 [HNP 应用宿主调试速用](HNP应用宿主调试速用.md)，设备测试结果见 [安装与调试记录](安装与调试记录.md)。HDC 独立包保留作对照；不要把它的受限网络身份与应用身份混用。

## 当前使用的路径

| 项目 | 位置或配置 |
| --- | --- |
| DevEco 本体 | `/Volumes/MacSSD/Applications/DevEco-Studio.app` |
| hdc 工具 | `/Volumes/MacSSD/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/toolchains/hdc` |
| 实例名称 | `MateBook Pro` |
| 实例和镜像根目录 | `/Volumes/MacSSD/Huawei` |
| 实例配置 | `/Volumes/MacSSD/Huawei/MateBook Pro/config.ini` |
| 镜像 | `system-image/HarmonyOS-7.0.0/pc_all_arm/` |
| 启动脚本输出 | `/Volumes/MacSSD/鸿蒙模拟器日志`，每次真正启动新建一份 |
| DevEco 自身日志 | `~/Library/Logs/Huawei/DevEcoStudio26.0` |

脚本使用 `bash` 和 `python3`，当前 Mac 已有这两项。`/Applications/DevEco-Studio.app` 是指向外置盘的启动壳，脚本也支持读取这个启动壳记录的实际路径。

其他电脑或路径变更时，在脚本开头的默认值处修改，或覆盖 `DEVECO_APP`、`HARMONY_EMULATOR_NAME`、`HARMONY_EMULATOR_ROOT`、`HARMONY_EMULATOR_IMAGE_ROOT`、`HARMONY_EMULATOR_LOG_DIR` 环境变量。名称与路径里的空格无需删除。

```bash
# 只打印启动命令，核对名称及路径，不调用模拟器和 hdc。
bash "/Volumes/MacSSD/Repositories/codex/docs/鸿蒙电脑模拟器/start-harmony-pc-emulator.sh" --dry-run
```

启动失败时按脚本提示查看本次日志。若工具提示无法读取进程状态，脚本会停止，避免重复启动；请在 Mac 普通终端执行。不要为此修改模拟器或 HOME 的权限。
