## 遇到的宿主限制

Codex 工具的受限环境最初禁止读取宿主进程表，官方模拟器工具打印 `pgrep: Cannot get process list` 并把实例误报为 `isRunning=false`；受限环境中的 hdc 查询也返回 `Connect server failed`。在获准的宿主执行环境中，相同工具返回实例运行中和 Connected。这是本次工具执行环境的限制，不能记作鸿蒙设备故障。

启动脚本遇到已知的进程读取失败提示会拒绝重复启动，不通过删除系统检查来处理。
