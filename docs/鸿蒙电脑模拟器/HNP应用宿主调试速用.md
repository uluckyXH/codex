# HNP 应用宿主调试速用

本入口面向当前鸿蒙 7 PC 模拟器中的专用调试应用 `com.codex.emulatorhnp`。它通过官方 private HNP 安装原生 Codex 和助手程序，应用只声明普通联网权限。它与直接通过 HDC shell 运行的调试包具有不同身份。

## 文件与配置

- 完整交付目录包含调试 HAP、原生程序压缩包、SHA256 校验、源码版本和本次设备测试报告。只有实际生成并验证的文件才在交付摘要中列出。
- HNP 内保留 `bin/`、`codex-path/`、`codex-resources/` 的相对布局；中文文档和许可证随外层交付包提供。
- URL、API Key 和个人 `config.toml` 不打入 HAP、HNP 或发布压缩包。由应用在私有目录单独接收，最终配置权限须为 `0600`。
- 模型固定使用 `gpt-5.6-terra`。最终安装、启动和查看日志的命令由本次设备报告提供；本说明不把未完成的集成写成可用命令。

## 目录与权限

`hnp-debug` 构建固定运行根 `/data/storage/el2/base/files/r`，并绑定已经实测的应用 UID。应用须先创建自己的受保护目录；Codex 继续检查目录祖先、所有者、权限及符号链接，失败即停止。

不要用此包覆盖 HiShell 安装，也不要用 HDC shell UID 2000 直接执行。卸载重装可能改变应用 UID，需要重新核验并构建。更新安装是否保留 UID，应以设备检查结果为准。

## 验收范围

已有最小 HNP 原生程序启动和联网成功的证据。完整 Codex 的模型响应、命令执行、文件修改、终端交互及重启恢复须分别验收，以同一版本的测试报告为准。

应用沙箱、联网权限与 Codex 的受限命令沙箱是不同机制。HNP 安装不会增加内核 namespace 或 Landlock 能力，也不会自动切换完全权限模式。
