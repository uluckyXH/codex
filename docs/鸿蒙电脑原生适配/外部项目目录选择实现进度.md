# 外部项目目录选择实现进度

日期：2026-10-04。范围：`harmony/terminal-host/entry/src/main/ets/pages/Index.ets`、`ProjectDirectoryPicker.ets` 及交接记录。本轮不改Rust、TerminalBridge、C++、HNP、构建脚本；不编译、不操作模拟器、不提交。主会话负责用户桌面 `1` 目录的Picker确认、编译、实际对话及创建/编辑/删除验收；新增sendText由主会话维护。

## 已确认的方案和边界

- 本机ETS SDK为API26、26.0.0.105。`picker.DocumentViewPicker(UIAbilityContext)`、`DocumentSelectMode.FOLDER`、`maxSelectNumber=1` 为正式接口。Picker本身无需新增权限；本轮不申请整个桌面、全盘或持久授权。[官方Picker说明](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-file-picker)
- 用系统 `fileUri.FileUri(uri).path` 取得对应沙箱路径，不手工去掉scheme、拼UID、替换固定目录、二次percent解码或将URI传入native cwd。官方明确转换本身不检查路径可访问性。[官方FileUri说明](https://github.com/openharmony/docs/blob/master/en/application-dev/reference/apis-core-file-kit/js-apis-file-fileuri.md)
- 选择后仅通过转换后的路径，以 `fileIo.OpenMode.READ_ONLY | DIR | NOFOLLOW` 打开目录并确认目录类型；不递归读取、创建、写入或改权限。取消或检查失败保留原cwd、留下错误stage/code。成功将原URI留在内存，cwd填真实沙箱路径；native子进程能否 `chdir`、读取、搜索仍须主会话实际确认，不能由ArkTS路径打开替代。
- 官方选择材料同页存在“临时读写”与“临时只读”描述，不能断言Picker只能授予只读。本实现默认只读指Codex的沙箱模式，授权结果须实际检查。临时权限退出/重启后清除；不调用 `persistPermission`、不加 `FILE_ACCESS_PERSIST`。[官方选择说明](https://github.com/openharmony/docs/blob/master/zh-cn/application-dev/file-management/select-user-file.md)、[官方持久授权说明](https://github.com/openharmony/docs/blob/master/zh-cn/application-dev/file-management/file-persistPermission.md)
- 独立“允许读写所选项目”按钮以 `authMode=true` 和此前已选原URI为defaultFilePathUri拉起授权，单目录，授权前后必须映射同一cwd。该接口没有读写位选项；用户确认后只读打开目录，再通过 `fileIo.access(path, READ_WRITE, LOCAL)` 检查，未作试写。检查通过不会修改Codex模式；选择可写模式也不会自动申请系统授权。[官方Picker字段](https://github.com/openharmony/docs/blob/master/zh-cn/application-dev/reference/apis-core-file-kit/js-apis-file-picker.md)、[官方权限检查](https://github.com/openharmony/docs/blob/master/zh-cn/application-dev/reference/apis-core-file-kit/js-apis-file-fs.md#fileioaccess12)
- ArkTS `Environment.getUserDesktopDir()`、对应Native `OH_Environment_GetUserDesktopDir` 返回当前应用视图中的Desktop沙箱根，不代表已经获准全目录访问。SDK26 ArkTS权限注释限定 `READ_WRITE_DESKTOP_DIRECTORY` 为API11版本；本轮只使用返回值作为Picker初始位置提示，真实授权仍由用户选择桌面 `1` 完成。获取提示失败则打开Picker默认位置，不猜另一个物理路径。[官方Environment说明](https://github.com/openharmony/docs/blob/master/en/application-dev/reference/apis-core-file-kit/js-apis-file-environment.md)
- 保留手工cwd输入、只读默认policy和主会话刚补的Select `.value`。两个启动按钮通过绑定的 `TabsController.changeIndex` 切换页签并同步selectedTab，保留onChange和animationDuration(0)。
- URI文档说明缺失query/fragment时可能返回null，SDK26却声明string；已作null兼容处理，避免普通本地URI访问 `.length` 失败。[官方URI说明](https://github.com/openharmony/docs/blob/master/en/application-dev/reference/apis-arkts/js-apis-uri.md)
- HDC与应用的目录/权限视图不同。HDC不存在或不能列目录不能证明应用及其子程序拒绝，也不允许通过修改系统目录权限解决。
