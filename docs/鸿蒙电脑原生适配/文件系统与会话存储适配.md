## 目录设计

| 内容 | 拟议位置与规则 |
| --- | --- |
| 程序包 | 用户可写且允许执行的固定目录，例如验证后的 `~/应用工具/鸿蒙Codex` |
| 用户配置与状态 | 默认使用上游 `~/.codex` 约定；已有自定义 CODEX_HOME 时尊重它 |
| 项目文件 | 用户选择并授权的本机目录，不硬编码其他设备用户编号 |
| 临时文件与套接字 | 使用已有目录抽象和实际可用的私有临时目录，检查路径长度与清理 |
| 凭据 | 独立于程序包；文件模式验证访问权限，安装和更新不覆盖 |

以上目录均为设计值。不能把 hdc 的调试视图、文件管理器显示名称或示例 `/storage/media/100/...` 路径直接认定为所有终端用户的真实路径。

## 路径与文件访问怎么改

1. 从实际用户环境解析主目录、当前目录和临时目录；缺失时返回错误，不拼接固定账号路径。
2. 保留 `Path`、`OsStr` 或已有路径抽象；不要把非 UTF-8 错误显示字符串再当作真实路径执行。
3. 测试中文、空格、组合字符、长路径、大小写行为和软链接；禁止预设文件系统大小写不敏感或完全等同 Linux。
4. 统一文件工具和 Shell 的路径授权，避免同一路径在一个入口受限、另一个入口可以越界。
5. 文件权限、可执行位和扩展属性是否被复制工具保留，纳入安装验收。

文件写入应沿用上游可恢复流程。原子替换只在满足相应文件系统条件时成立；跨卷移动、目录授权撤销、磁盘满和文件被删除应有明确错误，不能静默丢失原文件。

## 会话、数据库与文件锁

[state 依赖](../../codex-rs/state/Cargo.toml)包含 SQLite 与 sqlx。交叉编译通过后，还需核对文件锁、WAL、共享内存、同步写入、重命名和异常恢复行为。

拟议方案：

- 保持既有数据库及会话格式，默认状态位于本地用户可写目录。
- 测试两个 CLI 实例并发访问、程序崩溃、系统休眠及空间不足。
- 会话恢复应验证实际内容和状态一致性，不能只看列表出现会话名称。
- 数据迁移记录最旧可读版本和不可逆变更；兼容性测试用副本，不能用真实用户目录试错。
- 不因一次锁失败就删除数据库、禁用同步或丢弃历史记录。

用户把状态放到同步盘或网络文件系统时，应单列支持情况，不把本地文件系统结果外推到该场景。

## 文件监听

当前使用 `notify::RecommendedWatcher`。需要核对锁定依赖对 OHOS 的后端选择，并验证创建、编辑、删除、重命名、目录树变化和权限撤销。

如果目标没有可靠事件后端，可设计轮询后端：明确轮询范围、间隔、去重、退避和休眠恢复。轮询是拟议替代方案，尚未实现；不能因为监听不可用就悄悄让配置、技能或插件变更永久不生效。

## 验收

无设备可做路径规则、补丁解析、会话格式和迁移的宿主回归，以及 SQLite 目标构建。真机必须覆盖：

| 用例 | 结果要求 |
| --- | --- |
| 中文路径项目读写和展示差异 | 文件内容与界面路径一致 |
| 文件只读、权限撤销、软链接越界 | 错误明确且权限不扩大 |
| 原子写中断或磁盘满 | 无静默截断，能保留或恢复已确认内容 |
| 多实例及崩溃后恢复 | 锁与数据库行为正确，旧会话可恢复 |
| 监听目录移除后重新创建 | 正确重新发现或明确报告状态 |
| 移动程序包并保留用户目录 | 程序资源和会话均可定位 |

本专题依赖[沙箱权限](沙箱与权限适配.md)，并为[安装指南](安装配置与运行指南.md)提供最终经验证的目录值。
