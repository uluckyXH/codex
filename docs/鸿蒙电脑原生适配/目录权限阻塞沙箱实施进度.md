## 公共 API 与编译契约

公共模块位于 `codex-uds`，Unix目标可用，无feature开关；arg0增加直接依赖即可，不存在反向依赖。

```rust
pub enum OhosRuntimePurpose { Aliases, ControlSockets }
pub fn ohos_runtime_base_contract() -> Option<&'static str>;
pub fn prepare_ohos_runtime_directory(purpose: OhosRuntimePurpose)
    -> std::io::Result<ProtectedRuntimeDirectory>;
pub fn validate_ohos_runtime_base(base: &std::path::Path)
    -> std::io::Result<ProtectedRuntimeDirectory>;
// ProtectedRuntimeDirectory:
// path() -> &Path
// revalidate() -> io::Result<()>
// create_new_subdirectory(&OsStr) -> io::Result<Self>
// open_lock_file(&OsStr) -> io::Result<File>
// validate_lock_file(&OsStr, &File) -> io::Result<()>
// AsRawFd（描述符保持CLOEXEC，不可交给受限命令）
```

`CODEX_OHOS_RUNTIME_BASE` 仅由 `option_env!` 在编译时绑定；没有默认值，运行时同名变量或 HOME/TMPDIR/CODEX_HOME/XDG/Context 不改变它。未绑定、路径失效、UID/模式不符或路径被替换时明确拒绝，不回退、不给全盘权限。

主会话本轮显式绑定唯一实验候选 `/data/storage/el2/base/files`。派生 `c<8位十六进制euid>/a`（aliases）、`c<UID>/s`（控制socket）。socket根40字节，保留完整64位摘要，连同分隔符及NUL共106字节，符合SDK的108字节容量。该计算不证明候选在HiShell独立ELF下可用，也不证明不同上下文中的同路径指向同一对象。

逐级 `openat(O_NOFOLLOW|O_DIRECTORY|O_CLOEXEC)` 验证并持有FD，使用同一父FD创建/复核。祖先必须root或当前euid所有、无组/其他写权限；root所有且sticky目录是显式受保护共享父目录例外。私有叶严格euid/0700，锁和socket为0600。既存对象不修复；只规范化本次新建并核对身份的对象。会话调用方保存guard到使用结束，锁定后再次验证锁身份。

## socket与沙箱行为

OHOS默认控制socket直接位于 `s/<SHA256>`，配置目录的规范路径只作为区分实例的摘要输入，不建立公共rendezvous目录或符号链接。启动锁后缀为 `.startup-lock`，监听竞争锁为 `.lock`，避免嵌套死锁。自定义Unix监听路径须直接处于固定 `s/` 根并使用完整64位小写摘要；外部公开路径拒绝。

监听器保存运行目录guard；旧socket仅在类型、owner、0600、单链接、无活跃监听且身份仍一致时清理。退出时只删除本次创建且身份未变的socket。陌生对象、替换对象及不安全模式保持原状。

bwrap继续遮蔽 `s/` 及其可见挂载别名，保留原有未知/直接socket挂载拒绝策略；`a/` 只按允许读取的最小范围只读恢复，不重绑整个运行根。显式禁止读取的路径发生冲突时拒绝。最终修正还拒绝写根与 `a/` 的祖先、自身、后代重叠，覆盖所有可见别名；否则父路径被重命名后，后续进程可能在旧名下创建未被旧沙箱覆盖的运行树。代价是不能把平台运行根或其祖先作为受限工具的写入项目根。

描述符在exec前复核且保持CLOEXEC，不加入bwrap保留FD清单。原有bwrap摘要校验和已打开文件执行机制未改变。
