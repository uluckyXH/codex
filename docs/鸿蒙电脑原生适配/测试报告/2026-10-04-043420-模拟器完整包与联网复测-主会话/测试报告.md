## 可复测命令

在 Mac 终端执行。命令保留已有配置，只临时限制重试和诊断模块。完整诊断含接口地址，分享前必须脱敏；不要发送配置文件。

```bash
# 指向本机 DevEco 自带的设备连接工具。
export PATH="/Volumes/MacSSD/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/toolchains:$PATH"
# 用固定模型、只读沙箱发送纯问候；关闭标准输入以免 HDC 等待 EOF。
hdc -t 127.0.0.1:5555 shell '
export HOME=/data/local/tmp/codex-emulator/home
export CODEX_HOME=/data/local/tmp/codex-emulator/state
export TMPDIR=/data/local/tmp/codex-emulator/tmp
export SHELL=/system/bin/sh TERM=xterm-256color
export RUST_LOG=codex_http_client=debug,hyper_util::client::legacy::connect=trace
cd /data/local/tmp/codex-emulator/workspace || exit 1
/bin/timeout -k 3 40 /data/local/tmp/codex-emulator/packages/codex-0.160.0-dev.harmony.g42542a8f1aad/bin/codex --strict-config exec --json --skip-git-repo-check --model gpt-5.6-terra --sandbox read-only --disable unbounded_connection_retries -c analytics.enabled=false -c model_providers.proxy.request_max_retries=0 -c model_providers.proxy.stream_max_retries=0 "请只回复鸿蒙原生会话验证成功，不要调用工具。" </dev/null
status=$?
echo "device_exit=$status"
exit "$status"
'
```

HDC 主机退出码不一定等于设备命令退出码，必须核对 `device_exit`。`exec` 的诊断输出在标准错误，不保证创建 TUI 日志文件。
