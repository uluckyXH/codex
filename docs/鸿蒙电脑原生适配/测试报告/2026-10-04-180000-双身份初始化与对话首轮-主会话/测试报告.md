## 已确认原因与修复方向

应用进程 `/proc/4055/stat` 的开头为 `4055 (latorhnp.second) S 139 0 0 …`。旧解析器要求进程组和会话号必须非零，误拒绝普通应用身份；全局观察因此中断。修复应允许观察这类记录，同时继续要求被控制的启动子进程具有正确的独立会话、实际身份及稳定句柄，不放宽发信号的归属条件。

空白 Shell 退出是另一项待确认问题。将保留首个 PTY 读取事件、终端属性、waitid 的退出码和信号，并复查零字节/EIO 读取是否过早关闭 master。失败时有界停止，不能无限循环，也不能把“请求关闭”写成“已回收”。修复后的编译及设备结果另行留档。

原生 Context 内的 chmod 后模式与 HDC `shell -b` 视图的模式显示不一致；本批以应用原生日志及 CLI 验证结果说明应用入口，不推断其他挂载视图或 HiShell 的行为。
