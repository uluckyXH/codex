## 入口行为

- `.command` 以独立参数调用同目录 `.sh`；可从 Finder 双击，也可在已有 Mac 终端运行 `.sh`。
- `.sh` 检查 Mac、真实 stdin/stdout TTY、hdc/expect/同目录 Tcl 文件，支持 `--help`，拒绝其他参数。
- 只连接指定设备，默认 `127.0.0.1:5555`；允许通过 `HARMONY_HDC` 和 `HARMONY_HDC_TARGET` 显式覆盖。不启动设备、不重启服务。
- 正式远端入口固定为 `/data/local/tmp/codex-emulator/start-codex.sh`。本会话没有修改或在测试中使用该正式入口。
- `.exp` 先进入交互式 `hdc shell`，等待 Shell 就绪，然后安全引用并调用远端启动脚本，保留输入输出与窗口尺寸传递。
- 远端 Shell 输出独立退出标记，Mac 以该值返回；没有收到标记时，即使 hdc 自身返回 0，也报告连接异常并返回 125。
- 不使用 `eval`，不读取或传递配置 Key，不生成会话录屏日志，不改变模型或沙箱模式。

## 设备验证方法与关键输出

在专用测试目录放置临时脚本，内容如下；未触碰正式 `start-codex.sh`：

```sh
#!/system/bin/sh
# 只检测终端与输入，不读取配置。
test -t 0; echo tty0=$?
test -t 1; echo tty1=$?
printf 'device-probe-ready\n'
IFS= read -r reply
printf 'typed=%s\n' "$reply"
exit 37
```

实际连接命令：

```sh

  /Volumes/MacSSD/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/toolchains/hdc \
  127.0.0.1:5555 \
  /data/local/tmp/codex-emulator/sandbox-agent/test-interactive-entry.sh
```

在提示后输入 `hello-鸿蒙`。实际输出：

```text

tty1=0
device-probe-ready
hello-鸿蒙
typed=hello-鸿蒙
```

Mac 工具收集到的进程退出码为 **37**。这里的 0 表示 `test -t` 判断为真；不是无终端。另行通过交互 hdc 的只读探测得到相同 TTY 结果。
