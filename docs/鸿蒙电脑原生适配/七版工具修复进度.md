## HM-03 包装接入参数（已实现）

`CODEX_HARMONY_PROCESS_DIAGNOSTICS=1` 显式启用进程诊断。可用于 `codex sandbox -- /usr/bin/sh -c pwd`，也可用于用户之后主动启动的 TUI/工具复测；包装脚本收集 stderr。该变量不是凭据，也不会传递父进程全部环境给 setup helper。阶段只包含固定标签、PID、errno/error kind、原始 wait status、退出码/信号/core-dump 标记，不打印命令参数、环境值、用户配置或文件正文。未启用时无额外阶段输出。

已保留 pipe/PTY 原有兼容退出码（PTY 某些路径为 1），另外输出原始状态；文件 helper 失败错误直接包含原始状态。159 不据此预判信号；`exit_code=Some(159), signal=None` 与 `exit_code=None, signal=Some(...)` 必须分开报告。只补定位证据，尚未证明真机根因，也未改变 syscall 或隔离策略。没有新增 doctor 命令参数。
