# 鸿蒙 PC 账号登录安装速用

先完成[新版安装与运行说明](新版安装与运行说明.md)中的安装和目录初始化。以下在鸿蒙 HiShell 的 zsh 中执行；保留账号登录功能，**本轮没有进行登录测试**。模型固定为 `gpt-5.6-terra`，账号需具备该模型的使用权限。

## 准备默认提供方配置

已有配置时手动编辑，不能同时保留 API 文档的 `model_provider = "proxy"` 并期待走账号认证；选择哪种认证由你决定。

```sh
# 新建配置，已有文件时停止；不覆盖已有账号或 API 配置
(
set -euC
# 新文件只开放当前身份的访问权限
umask 077
# 离线初始化并取得默认 state；显式 CODEX_HOME 继续生效
harmony_paths=$(codex doctor --initialize-data-directories)
harmony_state=$(printf '%s\n' "$harmony_paths" | sed -n 's/^state=//p')
harmony_config_dir=${CODEX_HOME:-$harmony_state}
# 初始化失败时不创建另一个未经验证的数据目录
test -n "$harmony_config_dir" && test -d "$harmony_config_dir"
# 使用默认 OpenAI 提供方，凭据保存在本机文件
cat > "$harmony_config_dir/config.toml" <<'TOML'
model = "gpt-5.6-terra"
model_reasoning_effort = "max"
cli_auth_credentials_store = "file"
mcp_oauth_credentials_store = "file"
approval_policy = "untrusted"
sandbox_mode = "workspace-write"
check_for_update_on_startup = false
TOML
# 仅输出配置位置，不输出认证内容
printf '配置文件：%s/config.toml\n' "$harmony_config_dir"
)
```

## 选择一种账号登录方式

```sh
# 设备码登录：在终端给出的页面输入一次性代码完成授权
codex login --device-auth
```

账号不支持设备码时，改用下面的普通登录；在同一台鸿蒙 PC 浏览器打开终端给出的地址并完成回调。

```sh
# 普通账号登录；无需与上面的设备码命令一起执行
codex login
```

```sh
# 查看本地保存的登录方式；这不能代替真实模型请求验证
codex login status
```

## 进入项目

```zsh
# 输入当前终端有权访问的项目绝对路径
read -r 'harmony_project?请输入项目的绝对路径：'
# 进入成功后启动固定模型
cd -- "$harmony_project" && codex --model gpt-5.6-terra
```

凭据写在配置目录中；不要分享 `auth.json`。日志与离线诊断命令见[新版安装与运行说明](新版安装与运行说明.md)。
