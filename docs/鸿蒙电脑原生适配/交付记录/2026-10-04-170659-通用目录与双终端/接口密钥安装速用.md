# 鸿蒙 PC 接口密钥安装速用

先完成[新版安装与运行说明](新版安装与运行说明.md)中的安装和目录初始化。以下在鸿蒙 HiShell 的 zsh 里执行；模型固定使用 `gpt-5.6-terra`。本轮不测试账号登录。

## 自定义 API：准备配置

已有配置时不要覆盖；手动将其放入初始化输出的 `state` 目录，或继续使用已明确设置的 `CODEX_HOME`。本轮不自动迁移旧数据。

```sh
# 新建配置；任何一步失败或文件已存在都会停止
(
set -euC
# 限制新建配置文件的访问权限
umask 077
# 让 CLI 验证并初始化数据目录，不读取认证文件、不调用模型
harmony_paths=$(codex doctor --initialize-data-directories)
# 从成功的初始化输出取得默认配置目录；尊重显式 CODEX_HOME
harmony_state=$(printf '%s\n' "$harmony_paths" | sed -n 's/^state=//p')
harmony_config_dir=${CODEX_HOME:-$harmony_state}
# 目录应已存在；失败时保留初始化错误，不猜测其他路径
test -n "$harmony_config_dir" && test -d "$harmony_config_dir"
# 写入 TOML 模板；下一步在本机编辑器中填写地址和 Key
cat > "$harmony_config_dir/config.toml" <<'TOML'
approvals_reviewer = "user"
model = "gpt-5.6-terra"
model_provider = "proxy"
service_tier = "default"
web_search = "live"
model_reasoning_effort = "max"
personality = "pragmatic"
plan_mode_reasoning_effort = "xhigh"
cli_auth_credentials_store = "file"
mcp_oauth_credentials_store = "file"
approval_policy = "untrusted"
sandbox_mode = "workspace-write"
check_for_update_on_startup = false

[model_providers.proxy]
base_url = "https://你的接口域名/v1"
requires_openai_auth = false
name = "OpenAI"
wire_api = "responses"
experimental_bearer_token = "在本机填写你的API Key"
TOML
# 只显示文件路径，不显示 Key
printf '请用本机编辑器填写地址和 Key：%s/config.toml\n' "$harmony_config_dir"
)
```

把 `base_url` 和 `experimental_bearer_token` 的示例值改成真实值，保留引号。`base_url` 通常以 `/v1` 结尾，不额外加 `/responses`；服务必须支持 Responses API、该模型和工具调用。`name = "OpenAI"` 可以保留；`proxy` 要与表名对应。当前源码也用 `OpenAI` 名称判断部分提供方行为，它并非仅是显示名。

Key 会保存在本机配置中，不要上传或提交该文件。此方式**无需 `codex login`**；`codex login status` 不能验证这个 Key 是否有效。

## 如果使用 OpenAI 官方 API Key

不要执行上面的自定义提供方模板。按[账号登录安装速用](账号登录安装速用.md)准备默认提供方配置后，用下面命令替代账号登录步骤：

```zsh
# 隐藏输入 Key，并通过标准输入保存；不会把 Key 放进命令参数
(
set -eu
read -rs 'harmony_api_key?粘贴 OpenAI API Key 后回车：'
printf '\n'
printf '%s' "$harmony_api_key" | codex login --with-api-key
)
```

## 在项目里运行

```zsh
# 输入当前终端有权访问的项目绝对路径
read -r 'harmony_project?请输入项目的绝对路径：'
# 进入成功后启动，模型仍为 gpt-5.6-terra
cd -- "$harmony_project" && codex --model gpt-5.6-terra
```

目录初始化、联网、工具执行分别验收。若受限执行失败，收集[安装说明](新版安装与运行说明.md)中的诊断，不会自动切换完全访问；用户主动选择完全访问后仍受鸿蒙系统权限约束。
