# 适配范围与源码清单

状态：设计稿；基线和证据等级见[文档导航](文档导航.md)。这是当前源码基线下的工作登记表，后续编译和上游变更发现的新问题继续追加。

## 首版必须形成的能力

原生启动；登录和模型请求；中文终端交互；读取、搜索和修改本机项目；执行原生 Shell 命令；显示差异；取消子进程；保存并恢复会话；执行经验证的文件与网络权限策略。图形 App、用户端自动更新、语音和桌面自动化不属于本轮首版目标。

## 如何保持清单完整

每次基线变化，对 Rust 条件编译、Cargo 条件依赖、构建脚本、Shell 路径、外部命令、原生库及下载清单重新检索。检索命中表示需要审查，不等于该文件必改；依赖库内部的目标选择还需实际 Cargo 依赖图和构建日志补充。

```sh
rg -n 'target_os|target_env|cfg\(unix\)|CARGO_CFG_TARGET' codex-rs scripts .github
rg -n '/proc/|/dev/|/etc/|/bin/|LD_LIBRARY_PATH|LD_PRELOAD' codex-rs
rg -n 'prctl|seccomp|landlock|inotify|posix_spawn|UnixStream|UnixListener' codex-rs
rg -n 'linux|musl|gnu|darwin|windows|dotslash' scripts/codex_package codex-cli .github/workflows
```

复核对象还包含非 Rust 文件、嵌入脚本、资源下载及测试工具。新增条目记录“触发条件、代码位置、拟议处理、验证层级、维护成本”，分配到专题和实施任务；不得以“全部兼容”代替真实构建与运行证据。
