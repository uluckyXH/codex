# 终端界面与系统集成适配

状态：设计稿。覆盖适配17—18。原生终端文本交互是首版必需能力，系统剪贴板、通知和图像属于单独验证的集成能力。

## 源码入口

- [TUI 依赖](../../codex-rs/tui/Cargo.toml)：crossterm、ratatui 及桌面集成依赖。
- [终端实现](../../codex-rs/tui/src/custom_terminal.rs)、[终端探测](../../codex-rs/tui/src/terminal_probe.rs)、[终端识别](../../codex-rs/terminal-detection)：终端查询、屏幕与输入输出行为。
- [剪贴板](../../codex-rs/tui/src/clipboard_copy.rs)、[通知](../../codex-rs/tui/src/notifications)：与终端及桌面环境交互。

## 编译依赖怎么改

当前 TUI 清单在 Linux 条件下引入 zbus，在非 Android 条件下引入 arboard；候选 OHOS 会命中这些条件。需要审核实际使用点和依赖图，不能从“系统提供终端”推导出 D-Bus、X11 或 Wayland 服务可用。

优先保留 crossterm/ratatui 的公共交互逻辑，核对锁定版本及仓库补丁对 OHOS 的支持。桌面后端缺失时，以条件依赖和模块边界隔离；不能只在界面菜单中隐藏功能而保留不兼容依赖。

## 输入与渲染

| 能力 | 拟议适配 | 真机验收 |
| --- | --- | --- |
| 普通键盘 | 保持现有事件流和组合键语义 | 输入、删除、方向键、历史、快捷键 |
| 中文与输入法 | 使用终端提供的文本输入，验证提交与候选过程 | 中文、英文混排、全角标点、组合字符 |
| 多行粘贴 | 验证 bracketed paste、换行和大段输入 | 粘贴后内容完整，不被意外当成快捷键 |
| 显示宽度 | 使用既有 Unicode 宽度逻辑，修正实际不兼容处 | 中文、emoji、换行及窄窗口 |
| ANSI 与颜色 | 基于已确认能力选择颜色与控制序列 | 基础色、真彩色、无颜色环境 |
| 屏幕与滚动 | 验证替代屏幕、历史滚动、重绘和窗口缩放 | 长输出、调整窗口、恢复屏幕 |
| 终端查询 | 查询需有超时，避免吞掉用户输入或等待不存在的回复 | 无响应终端仍能启动和输入 |
| 非交互输出 | 保持 exec 等非 TTY 路径与编码正确 | 输出重定向、管道和机器读取结果 |

退出、崩溃和用户取消时需要恢复终端模式与光标。输入模式恢复与[进程取消](进程执行与终端适配.md)共同验收。

## 系统集成边界

剪贴板分为文本复制、文本粘贴和图片粘贴。终端能粘贴文本，不代表系统剪贴板 API 或图片接口可用。可先保留终端原生文本输入，额外能力经过后端验证才启用。

通知可按终端支持情况选择已有 BEL/OSC 方式；桌面通知需另查鸿蒙接口。浏览器自动打开失败时提供正常可见的链接，登录流程按[网络专题](网络登录与凭据适配.md)处理。

首版暂缓能力应在用户调用时明确提示，不显示成功却没有执行。缺少剪贴板、通知或终端图像，不应阻止普通文本聊天和编码任务。

## 验证层级

宿主侧可复用布局、输入解析和快照测试；新增测试聚焦实际修改的行为，不为中文文档本身增加产品测试。交叉编译确认桌面依赖正确隔离。

商业鸿蒙原生终端必须验证真实输入法、粘贴、缩放和退出恢复。模拟终端、截图及宿主快照只能辅助，不能替代该验收。型号和系统确定后记录终端名称、版本与实际支持能力。
